Privacy Policy for QR Code Scanner

TL;DR: This extension does not collect, store, or transmit any user data whatsoever. All QR code scanning happens locally in your browser.

Data Collection

QR Code Scanner does NOT collect any user data. We do not:

  • Track your browsing history
  • Collect personal information
  • Store any data from scanned QR codes
  • Send any information to external servers
  • Use analytics or tracking tools
  • Share data with third parties

How the Extension Works

When you use QR Code Scanner:

  • The extension only activates when you click the extension icon and press the "Scan Page for QR Codes" button
  • It analyzes images and canvas elements on the current webpage
  • All processing happens locally in your browser using JavaScript
  • Decoded QR code data is displayed to you in the popup
  • No data is sent to any server or stored anywhere
  • When you close the popup, all scanned data is cleared from memory

Permissions Used

The extension requests the following permissions, and here's why:

activeTab Permission

This permission allows the extension to access the content of the current tab when you click the extension icon and initiate a scan. This is necessary to read and analyze images on the page.

scripting Permission

This permission allows the extension to inject the content script that analyzes images and canvas elements on the page to detect and decode QR codes.

Content Scripts on All URLs

The extension's content script is registered to work on all URLs because QR codes can appear on any website. However, the script only performs actions when you explicitly click the scan button. It does not run automatically in the background.

Third-Party Libraries

This extension uses the jsQR library (by cozmo) for QR code decoding. This library runs entirely in your browser and does not communicate with any external servers.

Data Storage

The extension does not use any form of storage (localStorage, chrome.storage, cookies, etc.). No data persists between sessions.

Changes to This Privacy Policy

If we make any changes to this privacy policy, we will update this page and the "Last Updated" date below. Any changes that involve data collection will require an update to the extension, which you will need to approve through the Chrome browser.
